# Apprendre à coder en Pyxel
Dans cette section, on va apprendre à programmer en Pyxel (J'apprends en même temps que vous). Apprenez (si vous ne savez pas) à programmer en Python. C'est très simple car Python est le meilleur langage pour ça ;). Le tuto est super, en plus ! [Python, la non-documentation](https://nondocumentation.garambrogne.net).

## Aspect technique
### Systèmes d'exploitation recommandés
* [Debian](https://fr.linux-console.net/?p=17890)
* [Microsoft Windows 11](https://www.microsoft.com/fr-fr/software-download/windows11) avec [WSL](https://learn.microsoft.com/fr-fr/windows/wsl/install) ou [CygWin](https://cygwin.com)
* [macOS](https://www.apple.com/fr/macos/)

Cet aspect est un peu "emmerdant" mais il est nécessaire pour débuter.
1. Assurez-vous d'avoir installé tous [ces](https://github.com/LostLevels94/Fuyu?tab=readme-ov-file#exigences-pour-coder-fuyu) programmes.
2. Ouvrez le dossier *PyCharm Project* dans le dossier dans lequel vous avez stocké le repository Fuyu.
3. Allez dans File/Settings/Project: PyCharm Project/Python Interpreter. Cliquez sur *Add interpreter* et ouvrez le fichier ```pyxel-demo/.pyxel-env/bin/python3.12```. Vous avez normalement créé le dossier pyxel-demo en installant Pyxel (lors de la création du venv).
4. Créez un fichier test_votrepseudo et commencez à coder. Vous copierez le tout dans main.py quand vous aurez terminé. Si besoin, copiez-collez le contenu de main.py dans votre fichier test. Cela sert à ne pas mettre le bazar (car les pythonistes n'aiment pas le bazar).
5. Ouf ! Terminé !
