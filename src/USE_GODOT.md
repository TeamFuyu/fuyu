# Comment utiliser le dossier Godot de Fuyu ?

## L'arborescence
Le projet Fuyu se décompose en plusieurs parties :

1. Racine du projet (NE RIEN AJOUTER)
	* project.godot
	* .editorconfig
	* .gitattributes
	* .gitignore
	* Assets
		- Contient tous les assets triés par dossier (NE PAS TOUCHER SI ON EST PAS SPRITER)
	* Resources
		- Contient les resources .tres ou .res, .cshape nécessaires dans le projet Godot
	* Scenes
		- Levels (une scène par niveau)
		- ui (les scènes nécessaires à l'UI)
		- global.tscn
		- index.tscn
	* Scripts
		- les scripts
	* .godot (DON'T TOUCH)
	* .theme
		- contient tous les fichiers de thèmes, d'icônes etc. (ASSUREZ-VOUS D'AVOIR AFFICHÉ LES ÉLÉMENTS MASQUÉS)
